# Formulários de fixação

Prontos para copiar no Microsoft Forms ou no Google Forms. Cada pergunta é de **escolha única**, obrigatória. Marque a opção certa como "resposta correta" na ferramenta e cole o texto de "Se acertou" / "Se errou" como mensagem de retorno, quando a ferramenta tiver.

Sugestão de configuração:

- Título e descrição como abaixo.
- Perguntar o nome da pessoa no início (campo de texto, obrigatório).
- Mostrar a pontuação no final.
- Permitir responder mais de uma vez (quem errar pode tentar de novo).

---

## Formulário 1 — Apontamentos de horas

**Título:** Apontamentos de horas · 5 perguntas

**Descrição:** Você assistiu ao vídeo. Agora responda estas 5 perguntas. Leva 2 minutos. Marque uma resposta em cada pergunta.

**Campo inicial:** Seu nome

---

**1. Para marcar as suas horas, qual botão você aperta?**

- ( ) Exportar
- (•) Novo apontamento
- ( ) Excluir

Se acertou: Isso. O botão vermelho Novo apontamento abre a janela para marcar as horas.
Se errou: O botão certo é o vermelho, Novo apontamento. Exportar manda a lista para uma planilha e Excluir apaga uma marcação.

---

**2. Você trabalhou 1 hora, ao mesmo tempo, para 4 empresas. Qual opção guarda 1 hora no total do dia?**

- ( ) Cada empresa fica com o tempo inteiro
- (•) Dividir o tempo entre as empresas

Se acertou: Isso. Dividir o tempo: cada empresa fica com 15 minutos e o dia soma 1 hora.
Se errou: A opção certa é Dividir o tempo. Com "tempo inteiro", cada empresa ficaria com 1 hora e o dia somaria 4 horas.

---

**3. O que acontece quando o seu dia passa de 8 horas?**

- ( ) O sistema não deixa marcar
- (•) O sistema guarda e avisa você e o seu gestor
- ( ) O sistema apaga a marcação

Se acertou: Isso. Nada é recusado. O sistema guarda e avisa você e o seu gestor.
Se errou: O sistema guarda a marcação do mesmo jeito. Ele só avisa você e o seu gestor.

---

**4. Onde você vê os dias em que marcou menos de 8 horas?**

- (•) No cartão Menos de 8 horas
- ( ) No botão Exportar
- ( ) No menu Ajuda

Se acertou: Isso. O cartão Menos de 8 horas mostra os dias que faltaram. Clique no dia para completar.
Se errou: É o cartão Menos de 8 horas, no meio da tela. Clique no dia para completar.

---

**5. Marcou errado. Como corrigir?**

- (•) Clicar duas vezes na linha errada
- ( ) Não dá para corrigir
- ( ) Pedir para o gestor

Se acertou: Isso. Dois cliques na linha abrem a janela para arrumar.
Se errou: Dá para corrigir, sim. Clique duas vezes na linha errada, arrume e aperte Salvar.

---

**Mensagem final:** Obrigado por responder. Se ficou alguma dúvida, pergunte ao seu gestor.

## Formulário 2 — Gerenciamento do Time (gestores)

**Título:** Gerenciamento do Time · 3 perguntas

**Descrição:** Você assistiu ao vídeo para gestores. Responda estas 3 perguntas.

**Campo inicial:** Seu nome

---

**1. Onde você vê quem passou de 8 horas no dia?**

- (•) Na aba Avisos
- ( ) Na aba Sintética
- ( ) No botão Exportar

Se acertou: Isso. A aba Avisos, ou o botão Avisos na tela principal.
Se errou: É a aba Avisos. O botão Avisos da tela principal fica vermelho enquanto tiver aviso por ver.

---

**2. Para marcar as férias de alguém da equipe, qual botão você aperta?**

- ( ) Novo apontamento
- (•) Lançar período
- ( ) Gerenciamento

Se acertou: Isso. Lançar período marca vários dias de uma vez.
Se errou: É Lançar período. Ele marca vários dias de uma vez, com a pessoa, o primeiro e o último dia e o motivo.

---

**3. Na aba Por usuário e data, o que quer dizer uma linha vermelha?**

- ( ) A pessoa foi desligada
- (•) A pessoa marcou menos ou mais horas do que o esperado
- ( ) O sistema deu erro

Se acertou: Isso. Vermelho é quem está fora do esperado, para menos ou para mais.
Se errou: Vermelho quer dizer que a pessoa marcou menos ou mais horas do que o esperado no período.

---

**Mensagem final:** Obrigado por responder.
